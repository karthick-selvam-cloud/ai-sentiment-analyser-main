# AI Sentiment Analyser

This project explores sentiment analysis using text processing and machine learning workflows, with a focus on practical experimentation and application prototypes.

## Overview
The repository contains scripts and project files related to:
- data preparation and preprocessing
- text classification concepts
- database creation and integration
- sentiment analysis app experimentation

## Main Files
- `dbcreation.py` — database setup scripts
- `dbbpyy.py` / `dbbcreattionsss.py` — supporting database-related scripts
- `Sentiment-Analysis-ML-Flask-App-main/` — a packaged Flask-style reference app or project directory
- `deeee.py`, `table craetion.py` — helper scripts used during testing or prototyping

## Requirements
- Python 3.9+
- Flask
- pandas
- NumPy
- scikit-learn

## Installation
```bash
git clone https://github.com/EzadAhamed/ai-sentiment-analyser.git
cd ai-sentiment-analyser
pip install -r requirements.txt
```

If `requirements.txt` is not present at the root, install the required libraries manually.

## Usage
Run the app from the project root or inside the Flask app folder:

```bash
python app.py
```

If the main application is within a nested folder, navigate into that directory and start it there.

## Notes
This repository appears to be a learning and experimentation project, so some files may be exploratory or prototype code.
